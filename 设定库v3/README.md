# 设定库 v3

本目录是小说世界观设定本体，供作者和写作模型直接查阅。

## 分类

- 01_世界与地理.md：世界基本规则、行星、种族、大陆、地理环境。
- 02_国家与地区.md：各国家、地区及其内部情况。
- 03_人物.md：主要人物、次要人物及人物关系。
- 04_系统与特殊能力.md：陈墨系统、杨佳琳系统及其他特殊能力。
- 05_武器载具与装备.md：机娘形态、歼-47、SA-47A、T-90M及其他重要装备。
- 06_组织与势力.md：圣光教、落殇联体相关组织结构及其他势力。
- 07_历史与古代文明.md：未央联合体、旅行者三号、方舟地下城及历史事件。
- 08_魔导技术与工业.md：魔法、魔导设备、材料、能源与工业体系。
- 09_经济货币与交易.md：货币、积分兑换、商店商品及已出现的经济参照。

## 使用原则

- 本目录只记录小说世界中的设定，不记录讨论过程、作者裁决问答、审计编号、来源索引或助手提案。
- 每个条目尽量只描述一个独立事实或规则，相关内容分开陈述。
- 按主题归属维护；跨主题内容以简短关联说明连接，不复制整段设定。
- 不把人物猜测、传闻、档案记载和客观事实混为一谈。若某条信息本身来自角色、档案或传闻，正文表述应保留其来源性质。
- 未确定的内容不擅自补齐，也不为了显得完整而创造参数。
- 小说正文中已经发生的事件与世界长期规则应分别表述，不能把一次事件中的表现直接推广为普遍规则。
- 本目录不代替小说正文。章节进度、待写剧情和创作讨论不属于世界观设定本体。

旧版「设定库」与「设定库v2」继续保留，v3 独立维护。
