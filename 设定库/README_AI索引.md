本文件保留旧路径，避免历史引用失效。**当前正式主题库已统一迁移至 [`设定库v2/README.md`](../设定库v2/README.md)。**新设定、作者裁决和后续修订请维护在 `设定库v2/`，不要在本旧目录建立第二份重复的“最新设定”。

## 使用方式
1. 首先读取 [v2 的完整主题索引](../设定库v2/README.md)，并按其中要求先读 `00_设定状态与写作规则.md)。
2. 当前场景需要什么，就读取 v2 中对应的人物、系统、国家、组织或技术文件；跨势力问题补读 `16_跨势力关系与战略边界.md)。
3. 尚未裁决或与正文冲突的内容，以 v2 的 `10_待确认项与冲突审计.md` 为入口；需要追溯讨论过程时，再查 `17_对话来源与裁决索引.md` 及 `duihua/` 中的原始对话导出。
4. 小说正文以仓库根目录的 `关于我被大运撞死后转生成机娘这档事儿.md` 为准。对话记录和综合审计总库用于追溯，不等于正文。
