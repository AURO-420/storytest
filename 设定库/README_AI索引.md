## 读取规则
1. 先读本文件和 00_设定状态与写作规则.md。
2. 当前情节涉及哪个人物、国家或组织，就优先读取对应主体文件；涉及两个或更多势力关系时，再读取 16_跨势力关系与战略边界.md。
3. 区分作者明确设定、正文已发生事实、角色推断、档案/对话中的陈述、旧版冲突和待确认项。
4. 文件未写明时，不自行补设定；标注“未确定”或询问作者。
5. 不要因追求完整而在多个主体文件中重复整段细节。主体事实只维护在所属文件，跨势力关系放在关系文件，必要时用简短交叉引用。
6. 10_待确认项与冲突审计.md 用于记录仍待核实内容与历史冲突；完整总库和原始聊天用于追溯，通常不需随场景加载。
