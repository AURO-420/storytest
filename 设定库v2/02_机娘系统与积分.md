# 机娘系统与积分

## 3. 机娘辅助系统：通用机制

### 3.1 基础设定
- 系统名称在初次启动界面显示为“机娘辅助系统 V3.7.2”。系统仅是辅助工具，没有独立人格，不主动发展自己的目标、情绪或任务线。
- 初始界面包含个人信息、系统商店、地图、数据收集、机体状态、设置等页面；面板只有陈墨本人可见。
- 初始阶段没有日常任务/常规等级体系；**第23章作者明确新增了隐藏成就与Lv 2进阶**，所以现行规则应改为：早期没有公开任务或常规等级成长机制；在满足特殊条件后，系统可以通过隐藏成就进阶。是否存在更多等级、更多隐藏成就尚未确定。
- 系统面板可记录系统实际管理或能取得的信息。不能凭空读取他人的思想、记忆、秘密、未观察到的信息；对外界的分析受观察、可测量信息和已知分析能力限制。
- 系统不会自动替陈墨作出战术决策、自动开火、自动预测所有故障或保证她永远不受伤。

### 3.2 积分、商店与数据收集
- 积分可通过数据收集、环境探索、战斗记录等途径获取；扫描新动植物、矿物、地图区域及特殊物体均可能产生积分。**按信息增量结算：**重复扫描已完整记录、没有新信息的对象通常不再获得积分；若发现新信息、状态变化或先前未记录的有效内容，仍可能产生积分。具体分值、权重和判定算法未设定，不得为了凑剧情随意编造。回收载具、从系统空间取出载具、拆解载具或取得部件本身不扣积分，也不奖励积分。
- 系统积分可以兑换异世界本地货币，汇率为1积分=10银币；本地货币不能反向兑换积分。
- 系统商店不赊购、不欠账，积分不足时拒绝交易。新增商店商品需单独纳入数据库，不默认可以购买任何物品或能力。
- 商店购买物品直接出现于陈墨手中或身边合适的固定位置，位置由系统依据物品体积/类型决定，陈墨不能自由指定精确坐标；没有确定的召唤粒子特效。
- 数据收集不是自动报告：系统可记录魔物外观、体型、环境等可观察信息，分析可测量的生物数据；不能直接知晓魔力水平、特殊能力、隐藏弱点或未经验证的属性。系统也可在陈墨看见魔物并主动要求分析时，分析食用价值、味道、适合的处理/烹饪方式，不需接触尸体或样本。
- 系统地图只绘制/记录陈墨亲自探索过的区域；未探索区域不会自动显示完整地图。已探索地区变化后，陈墨再次到达时才更新，不会远程实时更新。
- 初次在荒野扫描新物种时正文结算过47积分；抵达黑石城时因持续采集，余额曾到127。系统鉴定硬盘曾发生模块故障，原本可能产生的40,000积分未结算且不可补发；该笔结算已放弃，后续不能补发。后来系统恢复后，另一件超古代定位电路板正常获得4,000积分。积分余额属于时间点数据，不能当作永久常量。
- 【作者明确】如果穿越时携带的衣服破损，系统可以免费、无限次地回收旧衣并提供一套新的衣物替换修复；如果只是脏了，系统不管。清洗、晾晒等日常过程仍由陈墨自行处理。

### 3.3 万能仓库与100米限制
- 【作者明确】系统空间是**万能仓库**，普通物品也可以存取；不能把它缩窄成只能收纳武器/载具。万能仓库不自动代表复制、刷新、时间停止、无限物资或任意远程操作。
- **容量与吞吐：**系统空间总储存容量无限，但入口/收纳操作存在单次或单位时间内的物理吞吐限制。Lv 2进阶将该物理吞吐能力翻倍，不是把总储存容量简单翻倍；“可以塞进一整艘歼星舰”只是说明处理大体积对象更顺畅的比喻，不是实际入口尺寸或载具尺度参数。
- 武器娘的自身武器与载具可以收回仓库。已确认：收回的载具再次召唤时保持收回前状态，包括剩余弹药、损伤及已消耗挂载，不会自动恢复原厂状态；整机彻底毁坏后的重建另按维修规则处理。
- 武器/载具必须在陈墨100米范围内才可系统远程链接、指挥、收回，相关规则以此前确认的“陈墨与载具机体最近点之间的直线距离”计算，不按中心点计算。授权连接在满足条件时自动建立并瞬间完成；超出100米后连接瞬间断开，不能远程指挥、收回、补充挂载或通过系统查看载具实时状态。**系统此时完全失去定位能力**，不显示方向、距离、坐标或其他位置线索。
- 陈墨不能通过系统远程操控飞机飞过来，也不能仅凭100米权限远程控制载具航向、速度、姿态、武器或普通雷达/ECM/ESM操作。
- 第25章证实：魔法传送阵可以把载具直接送出100米范围，使陈墨当下无法调用系统回收。系统的距离限制不会自动阻止外界空间法术，也不会给载具套上防传送锁。

### 3.4 载具维护、状态与控制
- 系统状态面板只能显示真实可取得的信息，例如已知损伤、已知系统开关状态、剩余挂载/弹药；未知内容应标未知或估计值。
- 系统可修复载具损伤，但载具在系统空间外时必须在地面停稳；损伤越大通常花费越多积分，修复可瞬间完成。系统空间属于特殊操作场景，空间内载具可直接维修，也可直接升级/改装，无须满足空间外的地面停稳条件。完全损坏部件可替换；整机全毁可重建，费用按所有部件价格总和；整机重建只恢复本体和原厂固定设备，后加装升级需重新购买。收回系统空间后引擎和机载系统关闭，但永久升级保留；损伤、剩余弹药、已消耗挂载保留。
- 系统拆解载具或取得部件只能在载具已进入系统空间时进行；载具在外部时，只能使用螺丝刀、扳手等常规方式手动拆解。系统取得部件会使原载具对应部位受损或缺失；部件可选择存入系统或以实体形式取出，取出后可作为普通部件使用。上述拆解/取件本身不消耗积分，也不产生积分。
- 购买升级确认并扣积分后立即生效，不需施工/安装；默认不改变外观，每种升级只购买一次，重复购买不叠加。升级不是可单独拆下、掉落或被炸飞的实体组件。
- 其他人只要会驾驶就能使用释放出来的歼-47及其升级；系统权限本身属于陈墨。载具重新释放后发动机和所有机载系统默认关闭，需要驾驶员主动启动。
