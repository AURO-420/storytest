# 设定库 v2｜完整主题索引

> 当前正式维护目录。用途是为小说作者和写作模型提供可直接复用、按主题检索的设定。此目录整合了旧版主题设定、作者裁决、正文审计与必要的技术参考；它不是小说正文，也不意味着所有未来剧情已经发生。
>
> 整理基准：截至 2026-10-27 的仓库正文、旧设定文件、综合审计总库和已上传的近期对话导出。

## 使用顺序

1. **先读 [00_设定状态与写作规则.md](00_设定状态与写作规则.md)**，了解证据标签、冲突处理与文风要求。
2. 读取 [01_故事进度与人物.md](01_故事进度与人物.md)，确认当前正文进度、人物关系与近期剧情边界。
3. 根据当前场景读取相应主题文件；涉及多个国家/组织时，再读 [16_跨势力关系与战略边界.md](16_跨势力关系与战略边界.md)。
4. 写作遇到冲突、缺口或未知设定时，查阅 [10_待确认项与冲突审计.md](10_待确认项与冲突审计.md)；需要追溯裁决上下文时，再查 [17_对话来源与裁决索引.md](17_对话来源与裁决索引.md) 和对应原始对话。

## 证据与状态标记

- **正文已发生**：小说当前原文确实写出的事件或事实。角色说过某句话，并不一定代表其内容已经被客观证实。
- **作者明确设定/裁决**：作者在对话或设定材料中明确决定，即使尚未写入正文，也可作为后续写作约束。
- **角色自述/转述**：角色或档案提供的信息，需保留其来源，不自动等于全知视角的客观真相。
- **角色推断**：人物基于现有证据得出的判断，可能正确，也可能不完整。
- **作者剧情规划**：未来可能采用的剧情方向；不可写进“已发生时间线”，除非正文实际完成并确认。
- **待确认/冲突**：现有信息不足或不同来源存在张力；不能静默删掉一边，也不能由模型自行决定哪边为真。
- **外部参考**：现实或游戏资料只用于辅助描写，除非作者明确采纳，不自动成为小说世界规则。
- **工作性提案，待作者审阅**：只供临时参考，不覆盖任何已确认设定；作者逐项接受、修改或删除后，才可转入对应正式主题文件。

## 维护原则

- 本目录为当前主题设定的主要维护位置；旧目录 `设定库/` 保留用于兼容和追溯，不再维护双份正文。
- 作者最新明确裁决优先于旧摘要和助手推测；但不得据此静默覆盖尚未解决的正文冲突，应在文件 10 中记录。
- 以剧情因果、人物选择和世界运行逻辑为优先。没有必要时不继续细拆行政流程、常识性工程环节或行动岗位，不为追求“完整”而写死所有细节。
- 不要把“系统/组织有能力”扩大为“能在任何条件下做到”；不要把某一载具或一次行动的特性推广为所有载具、全体成员或所有场景的通则。
- 正文原件位于仓库根目录 `关于我被大运撞死后转生成机娘这档事儿.md`。对话导出在 `duihua/`，用于追溯裁决过程而不是每次写作都整份加载。
- 综合档案 `机娘小说_完整设定与审计总库_2026-10-25.md` 是历史合并与审计归档，内容可能同时包含旧版本；遇到差异时应核对本目录的最新裁决、正文和来源记录。
- 文件 18 是单独的审阅草案：作者没有明确采纳之前，它只代表助手整理的保守建议，不得作为正式世界观或正文事实。
