# 设定库 v2｜按主题拆分

> 本目录保存按主体和功能拆分后的详细设定。新增或修订设定时，以本目录对应主题文件为主要维护位置。

## 文件地图
- [11｜圣光教](11_圣光教.md)：组织、派系、行动、记录仪/中继网络、与陈墨相关事件。
- [12｜落殇社会主义民主联合体](12_落殇社会主义民主联合体.md)：制度环境、社会、对外立场、宗教活动边界。
- [13｜塞拉利昂所属王国](13_塞拉利昂所属王国.md)：国家情况、留学人才、工业瓶颈、进口反应堆、技术追赶策略。
- [14｜奥塔尼亚四国](14_奥塔尼亚四国.md)：四国格局、调度中心、参观与留学渠道、核心技术保护。
- [15｜魔导技术与工业体系](15_魔导技术与工业体系.md)：通用魔导技术、紫金、魔晶、聚合反应堆、工业与留影媒介。
- [16｜跨势力关系与战略边界](16_跨势力关系与战略边界.md)：不同国家和组织之间的关系裁决、合作边界与战略弹性。

## 维护原则
- 主体事实放在所属主体文件；通用技术机制放在 15；跨势力关系放在 16。
- 其他文件只保留必要摘要和交叉引用，避免整段复制导致未来版本不一致。
- 作者明确裁决优先于旧摘要与助手推断；不确定的行动环节保留弹性，不为追求完整而过度细化。
- 原 `设定库/11_…` 至 `设定库/16_…` 路径保留为兼容提示，详细内容以本目录为准。
