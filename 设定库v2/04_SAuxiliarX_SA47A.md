## 写作模型优先读取的硬规则（作者裁决摘要）

### 挂载与弹舱兼容
- SA-47A采用模块化挂点/挂架设计。作者确认的兼容原则是：理论上，只要武器/挂载的尺寸确实能放入其弹舱，就可以考虑通过相应挂架安装；这不是说所有挂载都能不经调整直接安装，也不代表忽略尺寸、接口和挂架适配。
- SA-47A的内置弹舱比歼-47更大，因此在尺寸和安装条件允许的前提下，SA-47A可以挂载歼-47能够使用的内置挂载。具体挂载数量、接口适配与兼容限制仍按本文件和相应挂载设定，不自行增加未定义武器。

### 雷达覆盖的条件
- SA-47A的10部KCC-307P分布式雷达按固定空间分区协同工作，各雷达职责不能任意互换。
- 只有全部雷达均正常工作时，系统才可实现既定覆盖范围内无搜索盲区；雷达系统没有冗余，任意一部雷达损坏都会导致搜索盲区。部分雷达关闭或故障时，不得继续写成“全空域毫无盲区”。
- “无盲区”不等于能够发现所有类型目标，也不取消探测距离、遮挡、干扰、目标特征等其他限制。主雷达与分布式雷达的具体参数仍以本文件参数表和原始资料为准。

### 能源、燃油与固定机炮
- SA-47A的燃油无限，机体/载具能源系统整体能源也无限；固定原厂机炮的总弹药无限，可持续补充。参数表中的“备弹510发”指单次装填容量，不是全生命周期总弹药上限。补充弹药的具体过程尚未定义。
- 满油燃油质量12.2吨是设计参数/标称值，不代表实际燃油质量始终固定。无限燃油规则与该标称质量分别记录，不能混为一谈。
- 满油、无外部挂载质量33.7吨仍是当前质量基准；推重比计算以当前实际整机质量为分母。不要沿用已废弃的旧分项预算，也不要将标称燃油质量当作恒定实测质量。

### 购买、替换与初始状态
- 购买SA-47A升级项目需按商店规则实际扣除500,000积分。该项目只能购买一次；购买后SA-47A替换原有歼-47，歼-47必须先回收到系统空间，才能完成替换。
- 新获得的SA-47A初始存放于系统空间，可随时取出，不需额外积分。它是一架全新载具，不继承歼-47的损伤、挂载或其他状态；自带原厂固定设备，但不带武器挂载，需另行购买/安装。
- SA-47A服从机娘系统通用的100米连接规则与收回/释放规则；取出后发动机和机载系统关闭，需要驾驶员主动启动。整机全毁后可按通用重建规则恢复，不需要重新购买SA-47A项目；重建只恢复本体及原厂固定设备，后装升级需按通用规则处理。

### 05\. 燃油、质量与推重比

这里需要特别注意一个数据库一致性问题。

你之前确定的满油、无外部挂载质量为 33.7 吨，现在又确定满油状态下的燃油质量为 12.2 吨。两个数据本身可以同时成立，但此前的分项质量预算不能原样保留。

| 项目         | 当前记录     |
| ---------- | -------- |
| 满油、无外部挂载质量 | 33.7 t   |
| 满油燃油质量     | 12.2 t   |
| 非燃油部分的合计质量 | 21.5 t   |
| 常规推重比      | 17:1     |
| 垂直起降模式推重比  | 3:1      |
| 关键结构速度上限设定 | Mach 4.6 |

非燃油部分的 21.5 吨，是由 33.7 − 12.2 计算得出。

此前的暂定质量预算将燃油设为 9.0 吨，其他部分合计 24.7 吨。将燃油改为 12.2 吨之后，如果仍保留其他所有分项，整机质量将变为 36.9 吨，与已确认的 33.7 吨冲突。

建议处理方式： 暂时保留你确认的 33.7 吨整机质量、12.2 吨燃油和两种推重比；废弃旧的分项质量预算，后续重新分配各系统质量。不要让小说 AI 自行选择 33.7 吨或 36.9 吨中的一个。

### 性能参数的小说用法

* 17:1 常规推重比： 用于表现极高的动力储备、强劲的加速能力和机动潜力，不应据此推断飞机在所有高度、速度下都能无限加速。

* 3:1 垂直起降推重比： 用于表现垂直起降模式下的强大推力储备；具体升力分配尚未确定。

* Mach 4.6： 设定为关键结构速度上限。超过该速度后，机体会出现强烈共振，最终导致结构解体。不要把它当作正常巡航速度。

* 其他速度、高度、航程、最大过载、燃油消耗率等数值仍需单独确定，不得仅凭推重比编造为官方参数。

### 10\. 小说 AI 专用一致性规则

以下规则建议作为设定集最前面的系统提示或项目级指令。

### SA-47A 描写约束

第一条：优先遵守设定数据库

当正文、临时推断与数据库冲突时，以已确认的数据库为准。不得为了让情节更戏剧化而擅自修改飞机参数。

第二条：区分事实、推断与未知

已确认参数可以直接写入正文；合理推断可以作为暂定解释；尚未确定的参数不得伪装成官方数据。必要时使用自然语言避开具体数字。

第三条：保持机械动作连续

写到升力舱、受油枪、机炮、弹舱和矢量喷口时，要考虑盖板开闭、机构动作、发射架位置及前后状态，不能让部件瞬间出现或消失。

第四条：采用具体的航空叙述

描写飞机时，优先交代飞行状态、动力变化、控制动作、传感器信息和武器动作。避免反复使用“先进的战机”“恐怖的火力”“划破天际”等空泛修饰。

第五条：不要把所有能力同时开启

雷达搜索、武器发射、垂直起降、超高速飞行与隐身状态应依据剧情环境合理安排。拥有某项能力不代表所有能力在任何情况下都没有限制。

第六条：武器名称必须准确

提及具体导弹、发动机、雷达或其他设备时，必须与数据库中的型号一致。没有指定的型号不得随意替换成其他现实装备。

第七条：不擅自扩展世界观

不得自行编造 SA-47A 的正式服役年份、生产数量、军种归属、驾驶员姓名、研发代号或历史战绩，并将其当成已确认事实。
