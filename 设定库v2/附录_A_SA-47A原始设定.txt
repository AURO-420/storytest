### 外形描写规则

* 机鼻细长、尖锐，外形参考歼-20。

* 机身采用宽体融合布局，机翼与机身之间具有连续的融合过渡。

* 主翼为前掠翼，前掠角 20°；后缘采用直线布局。

* 鸭翼位于主翼前方，与主翼分离，根部可以与机身平滑融合。

* 全机不设置传统垂直尾翼。

* 机翼、机身和喷口应体现明确的机械结构，但关闭状态下的设备盖板尽量与机身表面齐平。

* 不得因为追求“科幻感”就随意增加环形光源、外露导弹、巨型垂尾或其他未设定部件。

### 03\. 主发动机系统

### 卡纳斯空气动力 WEP-4 型发动机

两台主发动机 · 后机身安装

| 数量     | 2 台             |
| ------ | --------------- |
| 安装位置   | 机身后部，两台发动机相互分离  |
| 安装倾角   | 约 10°           |
| 默认排气方向 | 相对水平面约向上 4°     |
| 喷口     | 扁平矩形、多段转向矢量结构   |
| 矢量能力   | 喷口可以向下偏转，参与垂直起降 |
| 发动机上方  | 存在类似机翼的结构       |
| 尾部中央   | 两台发动机之间有倒 V 形凹口 |

角度记录必须分开： 发动机本体约 10° 的安装倾角，与默认排气方向约向上 4° 是两个不同参数。小说 AI 不得将它们合并为同一个角度。

两台发动机之间的倒 V 形凹口目前只确定为外形特征，不能自行宣称它是雷达、散热器、尾喷口或其他设备。

发动机推力、加力燃烧室具体结构、推力矢量转动范围和燃油消耗率均尚未单独确定。

### 04\. 独立升力系统

### 卡纳斯空气动力「白骑士」YFL-7D 型发动机

| 型号     | YFL-7D                          |
| ------ | ------------------------------- |
| 数量     | 2 台                             |
| 位置     | 座舱后方、主翼前方、机身上部                  |
| 排列     | 沿机身纵向前后排列，不是左右并排                |
| 舱盖     | 左右盖板覆盖升力系统舱口                    |
| 开启形式   | 参考《流浪地球2》双开门式结构                 |
| 垂直起降方式 | 两台 YFL-7D 与两台 WEP-4 的向下矢量推力共同参与 |

小说中，垂直起降可以按以下叙述顺序展开：

* 飞机进入垂直起降模式。

* 升力系统盖板开启。

* YFL-7D 升力系统启动。

* WEP-4 矢量喷口转向下方。

* 飞控系统协调升力、姿态和方向控制。

* 飞机起飞、悬停或进入过渡飞行阶段。

这是推荐的小说表现顺序，不代表所有盖板、发动机必须严格按照这一顺序动作。具体的启动时序、升力分配、悬停限制和转换条件尚未设定。

### 05\. 燃油、质量与推重比

这里需要特别注意一个数据库一致性问题。

你之前确定的满油、无外部挂载质量为 33.7 吨，现在又确定满油状态下的燃油质量为 12.2 吨。两个数据本身可以同时成立，但此前的分项质量预算不能原样保留。

| 项目         | 当前记录     |
| ---------- | -------- |
| 满油、无外部挂载质量 | 33.7 t   |
| 满油燃油质量     | 12.2 t   |
| 非燃油部分的合计质量 | 21.5 t   |
| 常规推重比      | 17:1     |
| 垂直起降模式推重比  | 3:1      |
| 关键结构速度上限设定 | Mach 4.6 |

非燃油部分的 21.5 吨，是由 33.7 − 12.2 计算得出。

此前的暂定质量预算将燃油设为 9.0 吨，其他部分合计 24.7 吨。将燃油改为 12.2 吨之后，如果仍保留其他所有分项，整机质量将变为 36.9 吨，与已确认的 33.7 吨冲突。

建议处理方式： 暂时保留你确认的 33.7 吨整机质量、12.2 吨燃油和两种推重比；废弃旧的分项质量预算，后续重新分配各系统质量。不要让小说 AI 自行选择 33.7 吨或 36.9 吨中的一个。

### 性能参数的小说用法

* 17:1 常规推重比： 用于表现极高的动力储备、强劲的加速能力和机动潜力，不应据此推断飞机在所有高度、速度下都能无限加速。

* 3:1 垂直起降推重比： 用于表现垂直起降模式下的强大推力储备；具体升力分配尚未确定。

* Mach 4.6： 设定为关键结构速度上限。超过该速度后，机体会出现强烈共振，最终导致结构解体。不要把它当作正常巡航速度。

* 其他速度、高度、航程、最大过载、燃油消耗率等数值仍需单独确定，不得仅凭推重比编造为官方参数。

### 06\. 雷达与探测系统

### 主雷达 MSK-1005

| 参数        | 已确认设定               |
| --------- | ------------------- |
| 型号        | MSK-1005            |
| 技术        | 氮化镓（GaN）雷达          |
| 同时扫描/跟踪目标 | 300 个               |
| 最大有效搜索距离  | 2,300 km            |
| 水平扫描范围    | 机头轴线左侧 155°、右侧 155° |
| 垂直扫描范围    | 向上 140°、向下 140°     |

这里的 2,300 km 是设定集中的最大有效搜索距离；目标类型、雷达截面积、探测条件和不同模式下的实际探测距离还没有细化。小说可以使用这一既定数值，但不要自动将其理解为对所有目标都能达到的稳定探测距离。

### KCC-307P 分布式固定雷达

全机另外设置 10 部 KCC-307P 固定雷达：

* 机背：2 部，负责上半球及上方侧向区域。

* 机头两侧：2 部，负责左右侧向区域的部分覆盖。

* 尾部：4 部，负责后方区域及剩余侧向盲区。

* 机腹：2 部，负责下半球及下方侧向区域。

主雷达与分布式雷达共同构成全向探测系统。小说描写时，可以表现目标信息由不同雷达共同提供，而不是每次探测都只能由机头主雷达完成。

### 告警与头盔显示

* 导弹接近告警系统能够提示来袭导弹的大致方向。

* 头盔显示系统能够呈现来袭方向等信息。

* 不应擅自把“大致方向提示”升级为精确显示导弹实时坐标、剩余燃料或敌方驾驶员身份。

### 07\. 武器系统与弹舱

### 主武器舱

| 项目   | 设定                          |
| ---- | --------------------------- |
| 位置   | 机腹内置弹舱                      |
| 挂点数量 | 10 个                        |
| 装载基准 | 可同时容纳 10 枚 AIM-120D 尺寸级别的导弹 |
| 挂架结构 | 模块化、可更换的挂架或发射架系统            |

“10 枚 AIM-120D 尺寸级别”是尺寸和容纳能力的基准，不代表所有导弹都能在不调整挂架的情况下直接装入。

### 两侧近距弹舱

* 左右机身各设置一个侧弹舱。

* 每个侧弹舱可容纳 3 枚导弹，共计 6 枚。

* 采用旋转式发射架。

* 发射时弹舱门开启，发射架转位，完成发射后关闭舱门。

* 两侧导弹全部发射完毕后，发射架能够主动收回。

* 设计用途包括 AIM-9、R-73 这一类近距红外制导导弹；具体兼容型号仍待确认。

### 野兽模式

* 最多 6 个外部挂点。

* 每侧最大外挂质量为 4 吨。

目前没有确认各挂点之间的具体载荷限制，也没有确定外部挂载时的速度限制。因此，小说可以表现其具备重载外挂机动任务能力，但不应凭空给每个挂点指定精确承载质量。

### 08\. 机头特殊设备

### 左侧：空中受油枪

* 安装在机头左侧。

* 平时由盖板覆盖，尽量与机身表面齐平。

* 需要空中受油时打开盖板，受油枪伸出。

* 完成后收回并关闭盖板。

* 受油枪长度、伸出角度及受油接口尺寸待定。

### 右侧：12 mm 机炮

| 参数  | 数值         |
| --- | ---------- |
| 口径  | 12 mm      |
| 射速  | 7,500 发/分钟 |
| 备弹量 | 510 发      |
| 盖板  | 平时关闭，使用时开启 |

按理论射速计算，510 发对应约 4.08 秒的连续射击时间。小说中可按实际情境描写点射、短促射击或持续射击，不必每次都写出精确弹药消耗量。

机炮数量、炮管数量、弹药具体类型、弹道参数和内部供弹结构仍未确定。

### 09\. 飞行性能与反卫星能力

目前已明确的性能设定只有：

* 满油、无外部挂载质量：33.7 吨。

* 常规推重比：17:1。

* 垂直起降模式推重比：3:1。

* 关键结构速度上限：Mach 4.6。

* 能够执行反卫星任务。

以下内容尚未正式定稿：

* 实用巡航速度与高速巡航范围。

* 实用升限。

* 作战半径、转场航程和不同载荷下的航程。

* 最大过载与持续盘旋能力。

* 反卫星武器型号、探测与跟踪链路、交战条件及任务流程。

* 垂直起降的最大载荷、悬停时间、环境限制。

在这些项目确定之前，小说 AI 可以描述飞机执行相关任务的事实，但不应擅自生成一组精确数字并将其视为正式设定。

### 10\. 小说 AI 专用一致性规则

以下规则建议作为设定集最前面的系统提示或项目级指令。

### SA-47A 描写约束

第一条：优先遵守设定数据库

当正文、临时推断与数据库冲突时，以已确认的数据库为准。不得为了让情节更戏剧化而擅自修改飞机参数。

第二条：区分事实、推断与未知

已确认参数可以直接写入正文；合理推断可以作为暂定解释；尚未确定的参数不得伪装成官方数据。必要时使用自然语言避开具体数字。

第三条：保持机械动作连续

写到升力舱、受油枪、机炮、弹舱和矢量喷口时，要考虑盖板开闭、机构动作、发射架位置及前后状态，不能让部件瞬间出现或消失。

第四条：采用具体的航空叙述

描写飞机时，优先交代飞行状态、动力变化、控制动作、传感器信息和武器动作。避免反复使用“先进的战机”“恐怖的火力”“划破天际”等空泛修饰。

第五条：不要把所有能力同时开启

雷达搜索、武器发射、垂直起降、超高速飞行与隐身状态应依据剧情环境合理安排。拥有某项能力不代表所有能力在任何情况下都没有限制。

第六条：武器名称必须准确

提及具体导弹、发动机、雷达或其他设备时，必须与数据库中的型号一致。没有指定的型号不得随意替换成其他现实装备。

第七条：不擅自扩展世界观

不得自行编造 SA-47A 的正式服役年份、生产数量、军种归属、驾驶员姓名、研发代号或历史战绩，并将其当成已确认事实。
